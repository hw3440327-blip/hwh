# 4.1.0 雨声木盒版验证

新增童话物件“雨声里的木盒”：在旧物修补铺观察木纹、合页与字痕，顺纹打磨、选择修法、旋紧两枚合页。连续开合盒盖控制真实雨声、滤波与三段主人配音；半掩盒盖先听雨，抬高后听年轻林姨与远行旧友的约定。闭盖淡出后保留播放位置，切段不会被旧请求失败中断。配音自然播完才计入heard，主动阅读单独记read；静音字幕也能完整通关。回应、归还林姨或放在窗边的选择会影响小镇物件与后续谈话，完成后进入相册，保存/导出/导入兼容旧存档。

本版先完成木盒切片；面包和植物保留4.0已有玩法。三日生活、主线八章与资源不被木盒互动推进或重置。新一生会重置木盒。

三段新MP3共23.328秒，使用已选“初版参考音色”同一配置预制，文本ASR核对与文件完整SHA通过。它们是合成角色演绎；私有参考与模型未公开。雨声来自已有授权实录，单独混音。既有213段旁白未更改。自动检查覆盖解码、样本输出和播放行为，不代表人工听感评估。

保留3.2.1原画处理、16幅7680像素宽背景、固定人物与建筑、独立环境动效。没有重新生成插画细节或锐化。约1.5–1.7K源图放大输出并非原生8K绘制。
