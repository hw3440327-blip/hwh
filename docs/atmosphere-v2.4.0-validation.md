# 2.4.0 场景与互动更新验证

本版增加冬日后街、晚饭后的厨房、社区手作室、清晨菜畦四张插画，按地点与人生阶段分配；共十五张背景。青年和银发主人公为独立透明素材，加入呼吸与舒展动态，可在设置中关闭。床边告别等不适合站立人物的场景不会强行加入站姿。

背景按地点显示潮光、水纹、窗光、浮尘、蒸汽与树影；特写可轻触产生水纹或微光。手记或互动打开时暂停场景动态，减少动态设置和系统偏好均会停用额外动画。

三种互动使用插画横幅与有质感的工作台。揉面同时支持轻按、键盘和拖动，一次拖动只计一次；木片可直接操作，也保留按钮和键盘；撒粉、浇水、透光和开花均有视觉反馈。资源奖励、互动进度和旧存档沿用原引擎。

环境声使用本项目的程序合成：23.7 秒立体声纹理、非周期涨落与小范围声像变化，去除之前的纯音鸟鸣。没有使用或声称野外实录。默认旁白继续使用玩家选择的 A 声线，原有 213 段音频和 227 处绑定保持完整。

验证结果：

- `npm test`：53 项通过、0 失败、0 跳过；涵盖故事、旧存档、三种互动及完整旁白资源。
- `npm run package:game`：构建并生成单 HTML 成品，全部资源内嵌。
- 开发版 Chromium：8 项体验检查通过，0 浏览器错误。覆盖主人公动态、特写触碰、四张新插画与晚年形象、真实环境声输出及关闭清理、拖动揉面与键盘混用、木片键盘操作、种花流程、390 像素手机布局及减少动态。
- 环境声检查使用原生 AudioContext，实际输出 RMS 非零；单独开启环境声时没有创建音调振荡器，关闭后音频上下文全部释放。此项不代表人工听感评估。
- 确切打包文件的离线 Chromium 检查：8 项通过。十五张背景及两个年龄人物均实际解码；默认旁白实际播放、暂停与恢复、连续讲述、风景两段音频顺序和主人公开关均通过。外部资源请求、系统语音调用、浏览器错误均为 0。
- 离线检查仅路由初始 HTTPS 文档为打包文件，其余网络请求一律阻断，没有绕过 file:// 限制。部分旁白跳至接近结尾以触发真实媒体结束事件，未将自动检查称为全篇人工试听。

浏览器明细：`atmosphere-v2.4.0-browser.json` 与 `narration-browser-v2.4.0-validation.json`。公开下载上传后另外校验字节与 ZIP 完整性；本地离线验证不证明网页预览或中国大陆免 VPN 访问。
