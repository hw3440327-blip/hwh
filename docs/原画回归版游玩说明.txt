《下一次春天》原画回归版 3.2.1

电脑游玩：先解压整个 ZIP，再用新版 Edge 或 Chrome 打开
下一次春天-电影生活版.html
请从解压后的文件夹打开，不要在压缩包或下载软件的预览中启动。

这一版的 16 幅主背景和互动背景均为 7680 像素宽，保留原比例。
它们恢复自 3.1.0 的原画，只做普通等比例放大，保留原来的柔和色彩与笔触。
没有重新生成和锐化细节；输出尺寸并不代表原生 8K 细节。
画面本体保持稳定；海面反光、炉光、茶汽和微尘单独流动，人物与建筑不会随波纹拉扯。
“看看风景”沿用同一幅 8K 插画；点击观察点、拖动镜头，并用＋／−靠近或退远。

故事页轻点文字，或按空格 / Enter，读完一段再继续。
可以沏茶、拾贝、摄影，也能烤面包、修木盒和种花。
沏茶时把壶嘴拖到杯口上方，停留倒水，松手停止；也可以使用添水按钮。
照片取自当前场景实际画面，保存最近六张，也可下载 JPEG。
互动没有倒计时和失败惩罚，可以随时离开，进度随旅程保存。
Esc 会先收起互动或特写，再回到故事。

旁白继续使用你选定的第一次参考音色：“春语 · 初版参考音色”。
故事页开启“故事朗读”，或进入“旅程手记 → 阅读与声音”调整。
配乐、身边的声音、朗读和音量可以分别开启。
关闭“流动的场景”或开启“减少动态”时，仍然保留完整 8K 插画。

插画、程序、字体、默认旁白与自然环境录音均内置，加载完成后可断网游玩。
首次打开需解析完整游戏文件，请给它一点时间。
默认旁白为预先制作的合成语音，无需连接系统联网语音服务。

旧版旅程可继续使用。换浏览器、移动文件或清理数据之前，先在
“旅程手记 → 这段旅程 → 收藏这段旅程”导出 JSON 备份。
之后可以从标题页或旅程手记导入。

素材尺寸与来源：ASSETS-8K.json、CLARITY-CREDITS.txt。
字体与声音许可：OFL-Noto.txt、NARRATION-CREDITS.txt、SOUND-CREDITS.txt，以及同包许可文件。
