# 2.3.0 内置旁白验证

默认声音采用玩家从三种实际试听音频中选择的 A：春语 · 温柔女声。它是神经网络合成语音，不是真人录音。原有系统音色保留为主动选择的选项。

- 213 个真实 MP3，24 kHz、单声道、48 kbps，合计 16,607,244 字节、2,759.496 秒；这包括互斥的故事分支，并非单次通关时长。
- 154 个故事段落版本、22 处风景基础讲解、36 处场景联系和 1 段试听，覆盖 227 处播放绑定。三个出发点、四条人生路线及全部 72 个风景讲解绑定均通过全文匹配。
- 制作工具校验正文与文本 SHA、模型及制作参数、每个 MP3 的文件摘要、非空且有限的 PCM 样本、解码和时长。入库前再次检查所有音频与当前故事一致，全部通过后才生成正式清单。
- `npm test`：53 项通过，0 失败、0 跳过。包括旧存档、故事路线、小互动、音频完整性及错文拒播。
- `npm run package:game`：通过；单 HTML 为 51,143,338 字节。Vite 提示单入口包超过 500 kB；这是单文件离线游戏的构建提示，不影响生成。
- 打包后的确切 HTML 在 Chromium 中完成 7 项真实媒体验证：默认音色、菜单试听、暂停与恢复、逐段连续讲述、两段风景音频顺序、手机布局和离线资源检查。使用原生 HTMLAudioElement，实际 currentTime 推进，无系统中文声音时仍能播放。
- 浏览器测试启用 offline，仅将初始 HTTPS 文档替换为打包文件，其他请求全部阻断；外部请求、系统语音调用和浏览器错误均为 0。没有绕过环境的 file:// 访问限制。为缩短测试，部分音频跳至接近结尾，仍由真实媒体结束事件触发后续播放。

详细浏览器结果见 `narration-browser-v2.3.0-validation.json`。自动检查确认资源与播放逻辑，不代替人工对声线甜美度、情感或每个字的发音作判断。A 的声音由玩家试听选择。公开下载的字节校验与网站访问验证另行进行；本地离线测试不证明中国大陆免 VPN 可访问。
