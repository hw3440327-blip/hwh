《下一次春天》电影生活版 3.1.0

先解压整个 ZIP，再用电脑的新版 Edge 或 Chrome 打开：
下一次春天-电影生活版.html
不要在压缩包预览或迅雷下载列表里直接预览游戏。

全部插画、循环短片、字体、默认旁白与真实环境声已经内置，下载后可断网游玩。
首次打开需要解析完整游戏文件，请稍等片刻。

这一版：
主人公重绘进六处场景，衣袖、手边细节与周围海光一同轻动。
八段绘本式动态镜头；不是连续剧情影片或完整动作动画。
看看风景：点观察光点进入动态特写，拖动镜头，按＋／−调整远近。
新增沏茶、拾贝与摄影，加上原来的面包、木盒和种花，共六种互动。

怎样进入：
故事页点“看看风景”，底部会出现适合当前地点的互动。
面包房、书店和部分生活章节可以沏茶；海堤可以拾贝；每处都能拍照。
旅程手记里的“小镇日常”也能查看可做的事情和已经留下的成果。

沏茶：选一种茶，把壶拖到杯子右上方，让壶嘴悬在杯沿上方，停一会儿。
水会持续落下，松手停止。水量足够后，收壶闻香，再捧起杯子。
不好拖动时，可以使用画面下方的添水按钮。
拾贝：找到三枚贝壳后，可以拖动摆放；方向键移动，空格旋转。
摄影：移动取景框，调整大小，写一句题字，再按快门。
照片取自当前画面的真实一帧；可以单独保存 JPEG，也会进入相册。
最多保留最近六张照片，照片和互动进度会随导出的存档一起带走。

读故事：轻点文字，或空格／Enter；读完本场再作选择。
Esc 先退出互动或特写，再回到故事，不会丢失当前段落。

声音默认关闭。故事页开启“故事朗读”，听按参考录音制作的“春语 · 初版参考音色”（第一次参考试听）。
开启“配乐与海风”，听原创背景乐与环境声。
旅程手记 → 阅读与声音，可以分别调节开关、音量、速度和动态。
“流动的场景”控制视频；“减少动态”也会停用视频与额外动画。
默认旁白不依赖系统联网音色。部分低性能设备可关闭动态，保留完整故事和互动。

进度自动保存在当前浏览器。换浏览器、移动 HTML 或清理数据前：
旅程手记 → 这段旅程 → 收藏这段旅程，导出 JSON 备份。
可以导入旧版本存档。每段新人生会重新开始当次互动和照片。

游戏含神经网络预制合成旁白，不是真人录音。
字体与声音来源、许可见同包的 OFL-Noto.txt、NARRATION-CREDITS.txt、LICENSE-ZipVoice.txt、LICENSE-Vocos.txt 和 SOUND-CREDITS.txt。

3.1 声音更新：按你的选择恢复第一次参考音色，用于全篇旁白；环境声改为真实录音。
在“旅程手记 → 阅读与声音”分别开启配乐、身边的声音和故事朗读。倒茶时水声跟随壶嘴，松手后停止。
