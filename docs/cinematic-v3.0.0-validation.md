# 3.0.0 电影生活版验证

主人公重绘进六处场景原画；移除独立贴在界面上的人物。共八段无声循环短片，每段 8 秒、24 fps、1280 像素宽、H.264/yuv420p。镜头以绘画为基础，通过局部连续形变、光影和运镜制作，包含衣袖、手部细节、树叶和水光；不宣称完整人物动作视频或逐帧剧情动画。源画留在制作工作区，成品、海报、制作脚本与源文件摘要入库，见 `public/films/SCENE-FILMS.json`。

风景特写播放同一场景的实际短片，支持拖动与镜头远近调整，保留原故事段落。原三种手作继续可用，新增茶壶连续倾注、拾贝摆放、实际画面取帧摄影。三种新体验不修改人生资源，各留下一个去重回忆；摄影保留最近六张 JPEG，题字与真实帧随存档导出。完成的茶席和海岸可在手记回看。
