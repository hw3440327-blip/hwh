# 下一次春天 · 小镇手作版 4.3.0

风停在这里，故事从你开始。

一个可以离线游玩的中文人生叙事游戏。22 岁的初秋，你带着行李来到栖屿镇，从住处、三餐和一份工作开始。房租、排班、休息、一次邀约和一顿热饭，构成这一生里具体的日子。8 章、36 个场景、4 条完整路线和 4 个终局，覆盖 22–82 岁；可以留下、回城、独处或寻找陪伴，没有强制婚育路线。

## 4.3 的小镇手作

面包房的三种口味、三种造型改用九幅不同的绘画切片。原料、木碗、烤盘、外套、纸袋和配方纸也更换为带材质的画稿；炉口直接使用原画。林姨装袋、工作和歇手腕分别使用对应姿态，人物下半身在工作台后遮挡。“走近手边”能放大查看操作，背景保持比例，不使用形变滤镜。

小屋有六件绘画摆件，落点重新对齐原画的窗台、木桌和床边小柜。可以直接沿台面挪动，也能调整大小和轻微转向；独立接触阴影、灯光与海风不改变原画。物品仍只有一件，换位置不会复制；旧花盆的成长日仍保留。

沿海书店新增三本三页的原创短篇，可以翻页、拖动书签、点击想再读的一句话并写页边话。书签绑定实际书名、页码和句子，阿禾会回应。海堤新增水边近景：换石子、拖动蓄力或用方向键轻抛/远抛，力道与石形影响跳水次数；也可以在沙上写话，亲手让一阵海水带走。没有评分，取消或中途离开不会记录一次完成的投石。书签、心事和布置都随旅程保存、导出和导入。

雨声木盒的三段角色声音保留既有第一次参考声线，分句重新合成，调整语速、句间停顿与音量起伏。开盖后先留一点雨声，再进入人声；雨声让出讲述的位置，短房间反射提供较近的空间感，闭盖仍淡出和保留位置。夜窗回忆采用既有原画淡入与独立雨滴，不拉扯背景。它仍是合成配音，情绪和自然度需要玩家实际试听判断。原有 213 段正文旁白未更换。

## 4.2 的面包房生活样板

从“去小镇走走 → 有光面包房”点画中的 **走近工作台**，或点“烤一炉自己的面包”。也可在“旅程手记 → 小镇日常”直接进入 **面包房里的一个下午**。旧食谱仍可在面包房画面中翻开，作为另一种简短玩法。

推门、挂外套，再走到工作台。把面粉和喜欢的牛奶、果干、芝麻拖进木碗；温水壶靠近碗口停留多久，加水就有多少。水量影响面团的轮廓、光泽、拖动反馈与揉制进度，水多时可以添面粉。原料可以组合，没有唯一正确配方。也可轻点原料、按住水壶的空格键，或用键盘揉面和调整长短。

面团推开、折回，渐渐变得可以整形。收圆、交织或划叶脉后，先把面团放上烤盘；进炉前还能拿回碗里重新调整。送入炉中后，颜色按实际游玩时间和炉火逐渐加深，由你观察、决定出炉。烤深了可以切薄配热汤。读对话、看海、翻配方、主动暂停、切后台或离开面包房时，炉火进度停住，没有失败扣分和强制倒计时。

林姨会装袋、做事和歇手腕。请教时她先收好手里的活，再示范；面团太紧或太黏时，初次也可能主动走近。你可以帮忙折纸袋，给她留出喝水的时间。跨日分享过面包并帮过忙后，她才会放心托你照看柜台，门边的客人会带着旧纸袋问起之前的味道。新增这些场景对话采用文字，既有内置故事配音和雨声木盒配音保持原版。

这一炉的水量、配料、形状、火候和出炉颜色可以留下，照着再做时仍能改。纸袋里的面包和薄片配汤会保留实际配料与形态，能带到小镇分享。给林姨留下明天早餐的约定，次日会被提起；重新做出并亲手递给她，才算完成这份约定。配方纸也持续出现在小镇画面中。这些记录随旅程保存和导出，不改变主线年龄、资源或阅读位置。

本版先完成面包房样板。书店、修补铺和小屋保留现有玩法；雨声另一端的旧友回应仍为后续故事方向。原有插画维持固定，新增人物和道具采用独立矢量分层动效，不对背景做形变。

## 4.1 的雨声木盒

从“去小镇走走 → 旧物修补铺”点画中的 **雨声里的木盒**，也可在“旅程手记 → 小镇日常”直接进入。顺着木纹打磨、选择保留旧痕或补一片叶纹、亲手旋紧合页，完成一只可以连续开合的盒子；拖动和键盘都能操作，没有倒计时或失败扣分。

盒盖微开时先漏出真实雨声，抬高后才能听见年轻林姨对临行旧友说的话：寄一封普通的信，等桂花再开时重逢。三段角色配音已内置，沿用玩家选定的第一次参考音色；闭盖淡出并保留播放位置，重新打开接着听。字幕可单独阅读，阅读和实际听完分开记录，静音也能完整继续。

你可以写下回应，把木盒归还林姨，或留在自己的窗边。归还后面包房会出现她的回应；留在家里则可随时再听那场雨。周予也会记得修盒的事，完成后的回忆进入相册。盒子、回应、去向和修补进度随旅程保存、导出和导入，旧存档无需重开；新一生重新开始。

这一版先完成木盒的童话互动。面包和植物仍沿用已有玩法。下一段已选定“雨声里出现新的声音，旧友在另一端回应”，当前版本尚未包含该后续。

## 4.0 的互动生活

在故事页选择“去小镇走走”，或在“旅程手记 → 小镇日常”进入 **初秋的三天**。这是 22 岁初来小镇时的独立生活片段，晚年的旅程也可以回看，不改变主线的年龄或阅读位置。

- **自由探索**：在蓝门小屋、面包房、沿海书店、旧物铺与海堤之间往返。画里的物件能观察，留下居民喜好和生活近况的线索。
- **居民关系**：林姨、阿禾与周予有三天各自的谈话。回答、亲手做的礼物会留到第二天；对方记得你做过什么，而非只显示一个好感数字。
- **制作与布置**：决定面包的配方、造型与炉火，亲手揉面并赠给居民；在小屋的三个位置摆放物件，写一张短卡片。过一夜后，植物和对话会有可见变化。

没有实时倒计时、每日登录要求或失败扣分。你决定什么时候回家休息、走到次日；随时离开都会保存。三天后仍可走动和布置，完整经历会留作一段相册回忆。

标题页已有旅程时也提供入口；旧版存档可以直接继续，新增进度随原有存档一同导出和导入。新一生重新开始这段生活。

## 保留的原画与稳定动效

16 幅背景恢复为 3.1.0 发布时的原画，保留原来的柔和色彩、笔触、光线和构图，移除 3.2.0 新生成和锐化的细节。为保留 7680 像素宽输出，只对原画做一次等比例双三次重采样，以 WebP quality 94 编码，不使用细节生成、超分辨率模型或调色。原图约为 1.5–1.7K，并非原生 8K 绘制；逐幅原图 Git 版本、源文件摘要、输出尺寸、重采样误差见 `public/art/ASSETS-8K.json`。

背景本体保持固定，独立的矢量光影、水面反光、茶汽与微尘提供轻微动态。人物、手、木梁和窗框不参与局部拉伸；已移除旧形变视频的运行路径。风景特写与摄影直接取自同一幅 8K 背景。相册列表使用独立缩略图，避免一次解码多张大图。

## 已选定的声音

默认旁白按玩家最新选择恢复为第一次参考音色，与试听页“对比上一次试读”相同：ZipVoice Distill FP32、4 步合成、速度 0.94。开场段落使用同一份试听音频，全篇沿用相同的参考片段与制作设置。它是合成声音，不能保证与参考录音完全一致；原始参考文件没有随游戏公开。所有故事、风景讲解与试听仍预先内置，可离线播放。

“身边的声音”改为有授权的真实海潮、雨声、鸟鸣、枝叶、炉火、纸页、木质轻敲与杯中落水录音。场景之间淡入淡出，旁白响起时自动降低；倒茶的连续水声跟随壶嘴停留，松手即退去。素材作者、许可与处理方式在声音设置以及 `public/audio/SOUND-CREDITS.txt` 中保留。

## 画面与互动

主人公保留在车站、面包房、书店、修补铺、厨房与菜畦的原画中，与场景共享透视、光线和遮挡。每个场景以固定插画和独立环境动效构成，人物不会随背景波纹弯曲。关闭“流动的场景”可保留清晰静态画面。

“看看风景”暂时收起文字；点击观察点，展开实际画面的动态特写，拖动镜头、拉近或退远，并阅读与当前故事有关的讲解。画面空处也可以停留，点击“回到故事里”才继续阅读。开启旁白后，风景细节会有讲述。

新增三种可保存的场景体验，与原来的三种手作共同组成六种互动：

- **借一盏茶的时间**：选择茉莉或桂花，拖动青花茶壶，让壶嘴靠近杯沿上方。停留时细水持续落下，松手停止；水量合适后醒茶、捧杯。也可以通过按钮添水。
- **潮汐留下的信**：在海堤找到三枚贝壳，拖动摆放，或用方向键移动、空格旋转，留下一小片自己的海岸。
- **把这一束光留下**：在当前场景移动取景框、调整取景大小，拍下真实画面的一帧，写上自己的话。照片可以下载 JPEG，也会出现在人生相册、随存档带走。保留最近 6 张。
- **烤一只小面包**：配料、轻按或拖动揉面、调整烤箱温度。
- **修补旧木盒**：直接转动木片，或使用键盘，合拢木纹。
- **照顾窗边小花**：挑选幼苗、浇水、推窗、托住新叶。

这些体验没有倒计时或失败惩罚，可以随时离开；进度随旅程保存。新增体验各留一段回忆，原有三件手作沿用一次性资源奖励。已经完成的茶席、贝壳摆放和手作成果，可以在“旅程手记 → 小镇日常”回看。

## 声音与阅读

声音默认关闭，主动开启后可以听到本项目原创配乐《把日子慢慢过》与按地点变化的环境声。在“阅读与声音”中可以分别控制配乐、环境声、旁白、音量、速度、文字大小和动态。场景动效没有独立音轨，避免与配乐、讲述抢声音。“流动的场景”可以单独关闭；“减少动态”和系统偏好也会停用环境动效。

默认“春语 · 初版参考音色”采用恢复的第一次参考音色，故事与风景讲解共 213 段内置神经网络合成音频，覆盖 227 处文本绑定。它不是真人录音，玩家无需安装语音包。“连续讲述”会在读完一段后翻到下一段，遇到选择停下；打开手记、互动或切后台时停止故事旁白，音乐和环境声在讲述时自动降低。

原来的系统本机与联网音色作为可选项保留；只有主动选择才会使用。联网音色是否可用取决于浏览器服务，内置声音不依赖这些服务。播放失败时设置会显示具体错误，可再次试听或切回内置声音。

配乐由浏览器 Web Audio 演奏原创乐谱；环境声与拟音来自内置真实录音，经过节选、滤波、层次混音和循环衔接。自动检查覆盖解码、文本识别、响度和播放行为，不代表全篇人工听感评估。

## 保存与继续

旅程、手记、阅读设置、当前段落、互动与照片会保存在当前浏览器中。九封来信随人生推进解锁，可以阅读并回信；回信仅保存在游戏里。八章人生回望记录走过的路，人生终幕后可以带着回响，再看一次春天。

“旅程手记 → 这段旅程 → 收藏这段旅程”可以导出 JSON。在移动游戏文件、换浏览器或清理浏览器数据前，先导出备份。之后可从标题页或旅程手记导入。旧版存档兼容，缺少新互动字段时从未开始状态继续。开启下一生会重置当次互动与照片。

## 开发与打包

需要 Node.js 22.12 或更新版本；当前环境使用 `.nvmrc` 指定的 24.19.0。

```sh
npm ci
npm run dev          # 端口 5173，监听 0.0.0.0
npm test             # 故事、路线、存档、互动与旁白资源校验
npm run build        # 生产构建到 dist
npm run preview      # 预览生产构建
npm run package:game # 生成完整离线 HTML
npm run package:web  # 生成按需加载的网站到 release/web/hwh
```

离线打包只读取本地 `dist`，核查插画、字体和图标，统一内嵌为 data URL，重复素材只保存一份。单 HTML 无需另取脚本、样式或媒体；只显示当前场景所需的背景和环境动效。ZIP 另包含游玩说明与字体、声音许可。

旁白重制流程：`scripts/list-narration.mjs` 枚举正文和讲解；`scripts/generate-reference-narration.py` 使用本地 ZipVoice 与私有参考录音，并逐段通过 SenseVoice 检查正文；`--first-reference-audition --steps 4 --speed .94 --threads 1` 保留第一次试听的完整配置与缓存；`scripts/build-narration-manifest.mjs` 核对精确文本、SHA-256、时长和解码。来源与许可见 `public/audio/NARRATION-CREDITS.txt`。

原画恢复脚本为 `scripts/prepare-8k-art.py`，只需要 Pillow 和包含 3.1.0 提交的 Git 历史。运行 `python scripts/prepare-8k-art.py --output release/art-original-restored --install`，从固定提交直接取出原画，经普通重采样后核对编码尺寸和色彩误差，再安装背景、缩略图和运行清单。`src/SceneMotion.jsx` 使用独立 SVG 元素，始终不修改原画的纹理坐标。

- `src/useMusic.js`、`src/musicScore.js`、`src/useSoundscape.js`、`src/ambienceClips.js`：原创乐谱、真实环境录音与互动拟音。
- `src/letters.js`、`src/LettersPanel.jsx`、`src/LifeReview.jsx`：来信、回信和人生回望。
- `public/art/*.webp`、`public/art/ASSETS-8K.json`：8K 输出背景与可核对的素材记录；`previews/` 为相册列表缩略图。
- `public/art/play-*.webp`：新互动的绘画茶席、透明瓷器与浅潮海岸。
- `public/fonts/`、`public/audio/`：中文字体、默认旁白及许可。

网站由 GitHub Pages 从 `main` 分支的 `/docs` 发布。`scripts/package-web.mjs` 为同一构建生成按需加载的网站，只复制实际引用的素材，追加内容摘要以更新声音缓存，不携带未引用的工作画稿；离线包独立保留完整媒体。公开访问不要求登录；下载包可离线游玩。云端网络验证不代表已验证中国大陆各地免 VPN 访问。
