# 下一次春天 · 声景故事版 2.3.0

风停在这里，故事从你开始。

一个可以离线游玩的中文人生叙事游戏。22 岁的初秋，你带着行李来到栖屿镇，从住处、三餐和一份工作开始，慢慢与人相识。此后经历扎根、中年转变、退休与晚年，直到 82 岁的下一次春天。房租、排班、休息、一次邀约和一顿热饭，构成这段人生里具体的日子。

沉浸版以手绘动画风格的全屏场景呈现小镇。文字逐段出现，镜头轻轻转换，风、雨和灯光陪着故事向前。

## 打开游戏

在现代桌面浏览器中打开 `release/下一次春天-声景故事版.html`，或先解压 2.3 成品压缩包，再打开其中同名的 HTML。图像、字体、程序、原创配乐和默认旁白已包含在单个文件里，无需安装 Node.js 或注册账号，可以离线游玩。首次打开网站需要加载文件，下载后的单文件游戏无需连接语音服务。

首次进入，点击“从这一刻出发”，填写名字、选择来时的故事，再“走进小镇”。已有旅程时，标题页会显示“继续这段人生”。旧版成品和压缩包会保留，新版另用“声景故事版”文件名。

手机浏览器若只预览下载的 HTML，可在电脑浏览器中打开成品。

## 怎么慢慢生活

- **读一段故事**：文字逐字出现。轻点文字区域，或按空格 / Enter，先读完整段，再继续下一段；“上一段”可以回看。
- **作一个选择**：读到本场最后一段，选项才会出现。想加快节奏，也可以点击“直接查看选择”。故事会等待你，不会自动替你决定。
- **看看风景**：暂时收起文字，每个地点保留两处不同的观察细节。点击光点会展开真实画面裁切的特写镜头，读到物件的生活细节和它与这一幕故事的联系。开启朗读后，讲解也会有声音。Esc 先收起特写、再回到故事，保留原来段落。
- **亲手过一天**：在面包房配料、揉面、调好烤箱温度；在旧物铺转动木片，拼合一只旧木盒；在窗边挑选幼苗、浇水、开窗，让小花慢慢舒展开来。故事里的暖色按钮和风景页都可以进入这些小事。
- **留下一点成果**：完成互动会留下独有回忆，让生活多一点余裕或与小镇更亲近。每件小事只收获一次；进度跟随存档，半途离开也会保留。“旅程手记 → 小镇日常”可以查看进展和成果。互动均可跳过，没有倒计时或失败惩罚。
- **翻开旅程手记**：打开右上角“旅程手记”会暂停阅读。这里可以查看旅程、人生相册、来信、随身手记、人生回望和阅读设置。
- **听听小镇**：声音默认关闭，主动开启后可以听到原创配乐《把日子慢慢过》和随场景变化的声景。配乐为 66 BPM 的慢拍钢琴、木琴与暖垫，64 小节、约 3 分 53 秒，有四段旋律与和声变化；在“阅读与声音”中可分别控制配乐、环境声和音量。
- **听故事慢慢讲**：故事页的“故事朗读”可开启中文讲述。默认“春语 · 温柔女声”采用试听 A 的声音，逐段预先合成，故事和风景讲解共 213 个音频文件。它保留自然停顿，并统一音量；“阅读与声音”中可以试听、调速与调整音量。“连续讲述”在读完一段后翻至下一段，遇到选项停下；玩家始终亲自选择。打开手记、进行小互动或切到后台时停止故事旁白，音乐和环境声在讲述时自动降低。
- **选择适合的音色**：默认旁白是预先制作的神经网络合成女声，随游戏内置，不是真人录音，也不依赖电脑安装的语音包。姓名仍显示在人物和存档界面，正文使用自然称呼，避免预录音频念出错误姓名。原来的系统本机与联网音色保留在下拉菜单，只有主动选择时才会使用。新版首次采用内置声音；以后会记住主动选择的声音类型。
- **某个声音没有播出来**：设置会保留具体错误提示，可点“再试听一次”。使用系统音色时，也可以明确切回“内置温柔旁白”。失败不会触发自动翻段，也不会在切后台、换段或刷新音色列表时反复重试。系统联网音色仍依赖浏览器供应商的服务；默认内置声音无需连接该服务。
- **找到舒服的节奏**：在“阅读与声音”中调整文字速度，选择整句出现、放大文字或减少动态。系统的减少动态偏好也会生效。

## 这一生里有什么

8 章、36 个故事场景，保留四条完整人生路线和四个终局，覆盖 22–82 岁。11 张全屏手绘动画风格场景包含车站、面包房、小屋日夜、修补铺、来信、花园，以及新增的沿海书店、早市、小院和海堤。相同地点共享画面，不同场景使用各自的故事联系，避免无关场景重复套用车站或卧室。

可以自定义姓名，从三个出发点开始，经历相识、工作与生活变化，收集回忆，写下只属于自己的手记。九封来信随人生推进而解锁，可以读信并选择回信；回信仅保存在游戏里。

八章人生回望会记下走过的路、作出的选择和留下的回忆。人生终幕之后，可以带着梦境般的回响，再看一次春天。

游戏从成年开始，无强制婚育路线。留下、回城、独处和寻求陪伴都有完整故事。

## 保存与继续

旅程、手记、阅读设置和当前阅读到的段落会保存在当前浏览器中。重新打开游戏后，从标题页点击“继续这段人生”。

在“旅程手记 → 这段旅程”中点击“收藏这段旅程”，可以导出 JSON 存档。移动游戏文件、换浏览器或清理浏览器数据前，请先导出。之后可在标题页“从存档继续”，或在旅程手记中导入，带上进度、手记与阅读位置继续生活。

旧版游戏的存档与回响可导入沉浸版。没有段落阅读记录的旧存档，会从所处场景的第一段开始。各浏览器和游戏文件位置的本地保存空间可能不同，导出文件可以帮助你带走旅程。

## 开发与打包

需要 Node.js 22.12 或更新版本；当前环境使用 `.nvmrc` 指定的 24.19.0。

```sh
cd /workspace/hwh
npm ci
npm run dev
```

开发服务器默认端口为 `5173`，监听 `0.0.0.0`。游戏不需要账号、数据库、API 密钥或外部素材服务。

```sh
npm test             # 故事图谱、路线、存档和轮回验证
npm run build        # 生产构建到 dist
npm run preview      # 预览生产构建
npm run package:game # 构建并生成 release/下一次春天-声景故事版.html
```

已有生产构建时，也可从任意目录运行 `node /workspace/hwh/scripts/package-game.mjs`。打包脚本只读取本地 `dist`，检查十一张插画、字体和图标，并把所需资源内嵌为 data URL。重复素材只保存一份，成品无需另取脚本、样式、字体、图像或默认旁白。配乐在本机合成。版本 ZIP 会分别保留；重新打包会更新同名“声景故事版”HTML。

旁白重新制作分为清单、离线生成和校验入库三个步骤：`scripts/list-narration.mjs` 枚举三个出发点、四条人生路线及全部风景讲解；`scripts/generate-narration.py` 使用本地 Kokoro v1.1-zh 模型生成音频；`scripts/build-narration-manifest.mjs` 核对正文、文件 SHA-256、时长及解码结果后生成清单。推理工具与模型只在制作时使用，玩家无需安装。模型来源与许可见 `public/audio/NARRATION-CREDITS.txt`。

## 内容结构

- `src/story.js`、`src/origins.js`：故事、人物、选项、回忆与出发点。扩写时保留现有场景和选项 ID，以兼容存档。
- `src/engine.js`：选择推进、资源、存档验证和轮回规则。
- `src/main.jsx`、`src/ImmersiveApp.jsx`、`src/immersive.css`：应用入口、标题与旅程手记、存档及阅读设置。
- `src/Opening.jsx`、`src/opening.css`：电影标题开场与角色引导。
- `src/CinematicScene.jsx`、`src/cinematic-scene.css`：全屏故事、逐段阅读、选择、风景观察和场景转换。
- `src/visuals.js`：场景插画与观察点。
- `src/useSoundscape.js`：本地合成的分场景声景和音量控制。
- `src/useMusic.js`、`src/musicScore.js`：原创乐谱、本地音色、配乐调度、朗读时自动压低与后台暂停。
- `src/useStoryNarration.js`、`src/useRecordedNarration.js`、`src/recordedNarration.js`、`src/narrationClips.js`：内置旁白、精确正文匹配、顺序播放与音色切换。
- `src/useNarration.js`、`src/narration.js`、`src/AudioSettings.jsx`：可选系统朗读、试听、错误恢复与声音设置。
- `src/activities.js`、`src/LifeActivity.jsx`、`src/life-activity.css`：三种可操作的小镇日常、互动进度、一次性收藏与反馈。
- `src/letters.js`、`src/LettersPanel.jsx`：来信与回信。
- `src/LifeReview.jsx`：人生回望。
- `scripts/package-game.mjs`：单文件离线成品打包。
- `public/art/immersive-*.png`、`public/art/immersive-*.webp`：十一张场景插画。
- `public/fonts/`：Noto Serif CJK SC 的中文字体子集及 OFL 许可证；未覆盖的姓名字符由系统字体补全。
- `public/audio/narration/`：内置中文旁白 MP3；制作来源及许可说明在 `public/audio/`。

所有界面、插画和默认旁白从游戏文件加载。配乐与声景通过浏览器 Web Audio 在玩家主动开启后合成，不需要额外下载音乐文件。选择系统音色时，是否可离线由所选系统声音决定。
